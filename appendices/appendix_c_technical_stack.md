# Appendix C - Technical Stack

The working stack behind the project included:

- VS Code as the IDE;
- Codex as the repo-level coding and reasoning assistant;
- PowerShell for local execution and file operations;
- Python scripts for inventory, diagnostics, working-copy generation, material routing, and clustering;
- Pillow, NumPy, OpenCV, scikit-image, and imageio for local image handling and hard technical diagnostics such as blur, tilt, geometry, contrast, clipping, and file-quality cues;
- scikit-learn, PyTorch, transformers, UMAP, and matplotlib for embedding-based review, semantic grouping, clustering experiments, model-assisted review surfaces, and visualization;
- CSV matrices for inventory, lane fit, defect logic, authenticity tiers, material routing, and series candidates;
- Markdown docs for scoring rules, processing order, repair boundaries, print-surface guidance, and lane taxonomy;
- a documented external repair stack including Lightroom, Photoshop, DxO PureRAW, Topaz Photo AI, Upscayl, Real-ESRGAN, and OpenAI GPT Image, treated as escalation tools rather than the whole workflow.
